# CosmoBork — прозрачная космическая сцена

Откройте `preview.html` в браузере. Кнопка «Манёвр» запускает коррекцию курса выбранной модели . Остальные кнопки меняют фон **под** сценой, позволяют посмотреть три корабля и остановить движение. Эта демонстрационная подложка не входит в рабочий слой.

## Как встроить в сайт

**HTML-блок:** скопируйте всё содержимое `embed-fragment.html` внутрь нужного раздела сайта. У раздела должны быть `position: relative` и заданная высота, например `min-height: 500px`. Сам фрагмент не меняет фон, шрифты или прокрутку страницы. Вставляйте один экземпляр на страницу.

```html
<section style="position:relative;min-height:500px">
  <!-- Здесь ваш существующий контент. -->
  <!-- Сюда вставьте содержимое embed-fragment.html. -->
</section>
```

**Через iframe:** загрузите `cosmobork.html` на свой хостинг и разместите внутри нужного раздела:

```html
<iframe
  src="/cosmobork.html"
  title="Декоративная космическая сцена"
  aria-hidden="true"
  tabindex="-1"
  style="position:absolute;inset:0;width:100%;height:100%;border:0;background:transparent;pointer-events:none"
></iframe>
```

Родитель iframe также должен иметь `position: relative` и высоту. Фон родительского сайта будет просвечивать через сцену. Удалите прежний слой анимации перед установкой, чтобы не запускать две сцены одновременно.

## Файлы

- `cosmobork.html` — рабочая самостоятельная страница с полностью прозрачным фоном, около 72 КБ. Все семь картинок встроены; дополнительные загрузки не нужны.
- `embed-fragment.html` — вариант для вставки в существующий HTML-блок, без глобальных стилей для `body`.
- `preview.html` — самостоятельный предпросмотр с переключением подложек. Работает и без интернета.
- `assets/*.webp` — оптимизированные изображения отдельно, если потребуются для другой интеграции. Для двух HTML-вариантов папка не обязательна.
- `build-info.json` — точные размеры файлов.
- `generation-prompts.json`, `pod-final-prompt.txt`, `turn-prompts.json` — промпты использованной встроенной генерации ImageGen.

## Что изменено

Три обновлённых металлических корабля, по два ракурса на каждый, с настоящим альфа-каналом. Переход между ракурсами совмещает силуэты; это лёгкая 2D-анимация с ощущением объёма. В начале и конце коррекции курса видны короткие импульсы маневровых двигателей. Одновременно отображается только один корабль — без маленького дублирующего силуэта внизу. Узкий янтарный выхлоп закреплён на соплах и поворачивается вместе с корпусом. Три визуальных плана звёзд, небольшие скопления, холодные и тёплые оттенки, медленный дрейф и редкие оптические блики. Дальние звёзды не мерцают. У каждой модели своя крейсерская скорость; несколько плавных коррекций курса за пролёт, инерционная ориентация корпуса и мягкое усиление тяги при манёвре. Редкие метеоры сохранены. Подписи G1–KZ сохранены без тяжёлых плашек.

Нет библиотек, веб-шрифтов, видео, запросов к GitHub или других внешних зависимостей. Свечение подготовлено заранее. Число частиц и размер холста ограничены; на мобильных устройствах применяется облегчённый режим. В скрытой вкладке или за пределами видимой области цикл останавливается. При системной настройке уменьшения движения остаются неподвижные звёзды.

## Необязательное управление

При прямой вставке фрагмента:

```js
CosmoBork.pause();
CosmoBork.resume();
CosmoBork.setQuality('eco'); // 'auto', 'eco', 'high'
CosmoBork.setSpeed(1);       // 0.25–4; обычная скорость — 1
CosmoBork.destroy();        // удалить сцену и её обработчики
```

## Проверено

Проверено в Chrome: 1440×900 и 390×844, светлая/тёмная/градиентная/сетчатая подложки, загрузка шести изображений, манёвры всех трёх моделей , прозрачность холста, переключение кораблей, пауза, уменьшение движения, скрытая вкладка и удаление сцены. В тестовом прогоне не было ошибок JavaScript и внешних сетевых запросов. На самом существующем сайте встраивание ещё не проверено: его страница не предоставлена.

Код опубликован в основной ветке https://github.com/DrummerIke/CosmoBork. Опубликованные HTML-файлы сверены с локальными по Git blob SHA. На действующий сайт вставку должен применить владелец сайта; GitHub Pages пока не включён.







У моделей разные скорость, инерция и длительность коррекций курса. Тяга включается короткими импульсами; между ними скорость сохраняется. Во время манёвра по корпусу проходит тонкий блик, ограниченный альфа-маской текущего ракурса. Проверена пятиминутная симуляция всех трёх моделей.




Добавлены спутник с двумя солнечными панелями (Canvas, 46 px), вращающийся астероид (WebP, 26 px) и редкая комета с прозрачным хвостом. Показывается не больше одного такого объекта одновременно; между пролётами есть паузы. На мобильном спутник и астероид ещё на 20% меньше. Кнопка «Спутник» в предпросмотре последовательно показывает все три объекта. CosmoBork.previewAmbient('satellite' / 'asteroid' / 'comet') — ручной предпросмотр. Спутник и хвост кометы рисуются кодом; астероид создан встроенным ImageGen, промпты — ambient-prompts.json.


Панели спутника теперь поворачиваются на шарнирах с небольшой задержкой друг относительно друга: меняются проекция и освещение. Корпус построен из граней с сортировкой по глубине. У кораблей более заметный крен, более частая смена ракурса и отклонение выхлопа при коррекции. Проверена пятиминутная симуляция, включая диапазон движения панелей.
