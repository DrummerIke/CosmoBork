# CosmoBork — реальные космические аппараты

Прозрачная декоративная сцена: «Буран», Space Shuttle и «Союз», звёзды, спутник с подвижными панелями, астероид и редкая комета.

Модели аппаратов построены из лёгкой геометрии и проецируются на Canvas. При манёвре меняется ракурс и освещение граней. Это стилизованные визуальные модели по реальным прототипам, а не инженерные копии и не симуляция орбитальной механики. Скорости и интервалы подобраны для фонового оформления сайта.

«Буран» и Shuttle имеют дельта-крыло, киль, остекление кабины и тёмную теплозащиту. У Shuttle показаны три главных сопла; в этой орбитальной сцене тяга исходит от двух двигателей маневрирования. У «Бурана» нет трёх главных двигателей Shuttle. У «Союза» показаны три отсека, две солнечные панели и кормовой двигатель. Между импульсами выхлоп гаснет, аппарат продолжает движение по инерции.

## Установка

Для HTML-блока скопируйте всё из `CosmoBork-embed-code.txt` внутрь раздела сайта с `position:relative` и заданной высотой, например `min-height:500px`. Удалите старый экземпляр сцены перед заменой. Фрагмент не меняет фон и стили страницы; слой не перехватывает клики.

Для iframe загрузите `cosmobork.html` на свой хостинг:

```html
<iframe src="/cosmobork.html" title="Космическая сцена" aria-hidden="true" tabindex="-1"
  style="position:absolute;inset:0;width:100%;height:100%;border:0;background:transparent;pointer-events:none"></iframe>
```

Родитель iframe должен иметь `position:relative` и высоту. На действующем сайте интеграция не проверена.

## Файлы и производительность

- `cosmobork.html` / `CosmoBork-full-code.txt` — полный код, около 34 КБ (около 14 КБ gzip).
- `embed-fragment.html` / `CosmoBork-embed-code.txt` — готовый фрагмент для HTML-блока.
- `preview.html` — демонстрация с переключением подложек, аппаратов и манёвров.
- `build-info.json` — точный размер сборки.
- `assets/asteroid.webp` — единственный растровый ресурс, также встроен в HTML. Для работы HTML отдельный файл не требуется.

Новых растровых изображений для аппаратов нет: геометрия встроена в код. Никаких библиотек, шрифтов, внешних запросов или WebGL. На мобильном понижены разрешение и частота отрисовки. В скрытой вкладке анимация останавливается; при уменьшении движения остаются неподвижные звёзды. Одновременно показан один аппарат и не больше одного дополнительного объекта.

Проверено в Chrome на 1440×900 и 390×844: модели, манёвры, прозрачность, управление, пауза, скрытая вкладка, уменьшение движения и очистка. Пятиминутная симуляция проверяет движение, инерцию и предел частиц. Код публикуется в main репозитория https://github.com/DrummerIke/CosmoBork; это не автоматическая установка на основной сайт.

## Управление

```js
CosmoBork.pause();
CosmoBork.resume();
CosmoBork.setQuality('eco'); // auto / eco / high
CosmoBork.setSpeed(1);       // 0.25–4
CosmoBork.preview(0);       // 0 Буран / 1 Shuttle / 2 Союз
CosmoBork.previewManeuver(0);
CosmoBork.previewAmbient('satellite'); // asteroid / comet
CosmoBork.destroy();
```
