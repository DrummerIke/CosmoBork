# CosmoBork

Прозрачная декоративная космическая сцена для существующего сайта.

- `cosmobork.html` — полная самостоятельная HTML-страница, около 115 КБ.
- `embed-fragment.html` — полный код для вставки в HTML-блок существующей страницы.
- `index.html` — демонстрация с переключением подложки и кнопкой «Манёвр».

Все шесть изображений встроены в HTML. Библиотеки, веб-шрифты и внешние загрузки не нужны. Фон сцены полностью прозрачный. Одновременно показывается один корабль; маленький дублирующий силуэт удалён.

## Установка

Удалите прежний код анимации. Скопируйте всё содержимое `embed-fragment.html` внутрь нужного раздела сайта. Родительскому разделу задайте `position: relative` и высоту (например, `min-height: 500px`). Сам фрагмент не меняет фон или прокрутку страницы. Вставляйте один экземпляр на страницу.

Для iframe загрузите `cosmobork.html` на свой хостинг и используйте его URL. Raw-адрес GitHub отдаёт исходный текст и не является адресом работающей HTML-страницы.

## Графика и движение

Три модели по два ракурса, переход с совмещением силуэтов, несколько плавных коррекций курса за пролёт, короткие импульсы маневровых двигателей. Звёздное поле с разными планами, оттенками и редкими бликами. Свечение подготовлено заранее; количество частиц и разрешение холста ограничены. В скрытой вкладке анимация останавливается; системное уменьшение движения поддерживается.

Проверено в Chrome на размерах 1440×900 и 390×844: прозрачность, загрузка изображений, манёвры, пауза и скрытая вкладка.
 
Корабли уменьшены примерно на треть: максимальная базовая ширина моделей — 185, 140 и 120 px, на мобильных ещё меньше. Спрайты сжаты под новые размеры.

У моделей разные скорость, инерция и длительность манёвров. Основная тяга работает короткими импульсами; между ними скорость сохраняется. При повороте по корпусу проходит тонкий блик, ограниченный альфа-маской корабля.
